01 / About

A bit about me

Hey! I'm Switly, a self-taught developer who loves building things just for the fun of it. Started around 2022 and haven't stopped since.

My main focus is Python and C# (.NET). I'm especially drawn to how things work under the hood — private servers, reverse engineering, and low-level memory stuff.

Most of my work revolves around game emulation and tooling. I've also built Telegram bots, REST APIs, and security utilities. If I find it interesting, I'll probably build it.
